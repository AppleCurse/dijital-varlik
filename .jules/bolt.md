## 2024-08-08 - Regex Optimization for Task Routing
**Learning:** For Python performance optimizations involving string matching in hot paths (like categorization heuristcs), using pre-compiled `re.compile(..., re.IGNORECASE)` objects and `len(pattern.findall(string))` is significantly faster than using substring counting via list comprehensions, while still maintaining correctness and avoiding the per-execution string allocation overhead.
**Action:** When implementing counting-based string heuristics, utilize pre-compiled regex objects with `findall` to avoid list comprehension allocations and improve execution speed.
